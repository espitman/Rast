Rast

ابزار سبک macOS برای مدیریت حرفه‌ای متن‌های فارسی و دوزبانه

آخرین Release مخزن GitHub
macOS 13+ · فارسی · راست‌چین هوشمند

متن فارسی را هرجا انتخاب کن، مرتب و راست‌چین ببین.

Rast متن انتخاب‌شده را از برنامه‌ها می‌گیرد و در پنجره‌ای شناور، با جهت درست برای هر خط نشان می‌دهد.

دانلود مستقیم DMG دانلود ZIP
نسخه فعلی: 1.0.6 دانلود بدون نیاز به سورس‌کد فونت مناسب فارسی و طراحی native
RTL Pad
این پنجره برای متن‌های فارسی و چندزبانه طراحی شده تا هر خط با جهت درست نمایش داده شود.
npm run build
اگر یک خط فارسی داشته باشد، همان خط راست‌چین می‌شود.
پنجره شناور همیشه بالای بقیه برنامه‌ها می‌ماند، اندازه‌اش ذخیره می‌شود، و برای کار روزمره با متن‌های فارسی مزاحمتی برای workflow ایجاد نمی‌کند.

چرا Rast؟

مشکل اصلی را حل می‌کند: نمایش درست متن فارسی در محیط‌هایی که ذاتاً برای RTL ساخته نشده‌اند.

Selection Detection

گرفتن متن از برنامه‌های دیگر

با استفاده از Accessibility API و fallbackهای لازم، متن انتخاب‌شده را از برنامه‌های مختلف می‌خواند و سریع در پنجره شناور باز می‌کند.

Smart Direction

تشخیص هوشمند جهت هر خط

خط فارسی راست‌چین می‌شود، خط انگلیسی چپ‌چین می‌ماند، و متن‌های mixed هم با منطق line-by-line نمایش داده می‌شوند.

Floating Workflow

سبک، سریع و بدون شلوغی

Rast یک utility کامل برای منوبار macOS است؛ نه Dock را شلوغ می‌کند، نه نیاز به محیط سنگین دارد، و همیشه در دسترس می‌ماند.

راهنمای شروع

بعد از نصب، فقط چند مرحله کوتاه باقی می‌ماند تا برنامه درست کار کند.

1
برنامه را به Applications منتقل کن فایل DMG را باز کن و `Rast.app` را به `Applications` بکش.
2
دسترسی Accessibility را فعال کن از داخل خود برنامه وارد مسیر System Settings → Privacy & Security → Accessibility شو و `Rast` را روشن کن.
3
متن را انتخاب کن و با پنجره شناور کار کن متن را در هر برنامه‌ای select کن، سپس از پنجره شناور یا منوبار برای نمایش RTL Pad استفاده کن.
امکانات اصلی
  • پنجره شناور شفاف و همیشه روی بقیه برنامه‌ها
  • نمایش هوشمند خط‌های فارسی و انگلیسی با جهت مستقل
  • ذخیره شدن اندازه پنجره بین اجراهای مختلف
  • دکمه‌های سریع Copy و Paste
  • منوی منوبار با دسترسی سریع به پنل و تنظیمات

سوال‌های رایج

چند نکته مهم که معمولاً کاربرها موقع نصب و استفاده می‌پرسند.

آیا برای استفاده نیاز به Xcode یا سورس‌کد دارم؟

نه. اگر فقط می‌خواهی برنامه را استفاده کنی، DMG یا ZIP کافی است و هیچ نیازی به ساختن پروژه از سورس نداری.

چرا برنامه Accessibility permission می‌خواهد؟

برای اینکه بتواند متن انتخاب‌شده را از برنامه‌های دیگر بخواند و تجربه‌ای شبیه ابزارهای translate/popover ارائه دهد.

اگر macOS اجازه اجرای برنامه را نداد چه کار کنم؟

چون این یک utility شخصی است، ممکن است Gatekeeper روی بعضی سیستم‌ها هشدار بدهد. در صورت نیاز می‌توانی از Open Anyway در تنظیمات امنیتی macOS استفاده کنی.

Rast برای کاربران فارسی‌زبان macOS ساخته شده تا متن دوزبانه را ساده‌تر و حرفه‌ای‌تر مدیریت کنند.
